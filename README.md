# De-Omega-Point

The official De-Omega-Point website: human-value-centric intelligence, digital systems and space technologies engineered for humanity's future.

## Live sites

- GitHub Pages: <https://de-omega-point.github.io/dopsite/>
- Full application: <https://de-omega-point.sammielee.chatgpt.site/>

The GitHub Pages edition is a static export of the public company site. Runtime-backed capabilities, including the AI Visibility check and administration tools, remain on the full application.

## Development

- `npm run dev` starts the local development server.
- `npm test` builds and verifies the application.
- `npm run export:github-pages` creates the static GitHub Pages edition after a successful build.
